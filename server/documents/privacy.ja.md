# Mochi のプライバシー

このプライバシー通知は、アカウントの作成または本サービスのご利用時に、**{{operator.name}}**（この Mochi サーバーの運営者）があなたの個人データをどのように収集、利用、共有するかを説明するものです。{{operator.name}} がデータ管理者となります。

## 収集する情報

このサーバーへのご登録および利用に際し、私たちは以下の情報を収集します:

- **アカウントデータ**: ユーザー名、選択した認証手段（メールアドレス、パスキー、認証アプリ、リカバリーコード、または第三者ログインプロバイダーのアカウント）、および追加されたプロフィール情報（表示名、アバター、自己紹介）。
- **作成したコンテンツ**: 投稿、メッセージ、コメント、ファイル、およびこのサーバーにインストールされたアプリを通じて公開することを選んだその他のデータ。
- **他の人のコンテンツ**: あなたや他のユーザーがフォロー、購読、またはやり取りしているためにこのサーバーに届く、他の Mochi サーバーや他のネットワーク上の人々の投稿、メッセージ、プロフィール情報。
- **報告**: あなたが誰かについて行った報告、または誰かがあなたについて行った報告は、Mochi 上のものか他のネットワークからのものかを問わず、このサーバーの管理者が対応できるよう保管されます。
- **技術データ**: IP アドレス、ブラウザ／デバイス情報、およびリクエストのタイムスタンプ。これらは、サービスを安全かつ稼働状態に保ち、不正利用を検出するために使用されます。
- **クッキー**: サインイン時にセッションクッキーが設定されます。これは不透明なセッション識別子のみを保存します。広告やサイトをまたぐトラッキングのためにクッキーを使用することはありません。

私たちはあなたの個人データを販売せず、広告主と共有することもありません。

## Mochi がデータをどう扱うか（重要事項）

Mochi は **ピアツーピア（P2P）ネットワーク** であり、単一サーバーのプラットフォームではありません。これにより、データの流れがプライバシー上重要な点で変わってきます:

- フォロワー、購読者、または共有スペースに公開したコンテンツは、それらのフォロワーや購読者をホストする **他の Mochi サーバーに複製されます**。{{operator.name}} は、自社が運営していないサーバー上のあなたのコンテンツのコピーを削除することはできません。投稿を削除すると、このサーバーは投稿を以前送信したピアに対して削除通知を送信しますが、削除は最善努力ベースであり、それらのピアの協力に依存します。
- 公開プロフィールを選択した場合、あなたの **アイデンティティ（ユーザー名、プロフィール、公開鍵）** は Mochi ディレクトリに公開され、他の Mochi ユーザーがあなたを見つけて連絡できるようになります。
- 直接的でプライベートなコンテンツ（下書き、プライベートノート、特定の宛先間のプライベートメッセージ）は、このサーバーと宛先のサーバー上にのみ留まり、公開 P2P ネットワークの一部にはなりません。
- このサーバーで **他のネットワークに接続** できる場合（他のサービスでお持ちのアカウントを連携する場合や、他のネットワークの人々がフォローしたりメッセージを送ったりできるアカウントをここでホストする場合）、そのアカウントを通じて公開または送信したものは、それらのネットワーク上のサーバーに送られます。それらは Mochi サーバーではなく、{{operator.name}} が運営するものでもありません。このようなアカウントはそのネットワーク上で公開され、一部のネットワークでは、あなたがフォローしているアカウントや「いいね」した投稿、さらに Bluesky ではあなたがブロックしている人も公開されます。後から何かを編集または削除するとリクエストが送信されますが、それらのサーバーはそのリクエストを無視する可能性があります。
- Mochi 上および他のネットワーク上でチャットする相手は、あなたがオンラインかどうかを見ることができます。これはチャットアプリの設定の **オンライン状態を表示** でオフにできます。
- 他のサーバー上の人について行った報告は、そのサーバーのモデレーターにも送られる場合がありますが、あなたの報告ではなくこのサーバーの報告として送られます。報告者が誰であるかは記載されません。

要するに、Mochi 上か他のネットワーク上かを問わず、他の人と共有することを選択したものは、設計上、{{operator.name}} の管理を越えて伝わっていきます。公開するコンテンツは、メールやその他の連合型の通信と同じように扱ってください。

## 第三者

関連機能をご利用の際、以下の第三者と必要最小限の個人データを共有します:

- **メールサービス**: 送信メール（サインインコード、アドレス確認、通知）は、{{operator.name}} が設定した SMTP プロバイダーを通じて送信されます。
- **第三者ログインプロバイダー**: Google、GitHub、Microsoft、Facebook、または他の OAuth プロバイダーでサインインすると、当該プロバイダーは、あなたが本サーバーにサインインしたことを把握し、メールアドレスおよび基本的なプロフィールデータを私たちと共有します。
- **決済プロバイダー**: マーケットプレイスアプリで購入する場合、決済は Stripe（または {{operator.name}} が設定した決済プロバイダー）によって処理されます。完全なカード情報は保存しません。
- **プッシュ通知サービス**: Android 版 Mochi アプリへの通知は Google の Firebase Cloud Messaging を通じて配信され、通知のタイトルと本文が伝送されます。Mastodon、Matrix、XMPP のアプリなど、別のアプリでこのサーバーにサインインする場合、その通知はそのアプリが使用するプッシュサービスを通じて配信され、通知の対象となるメッセージが含まれることがあります。
- **認証局**: このサーバーが自身のドメインの下で Bluesky アカウントをホストする場合、各アカウントのアドレスにはセキュリティ証明書が発行されます。認証局は発行したすべての証明書を公開ログに掲載するため、それらのアドレスはそこに記載されます。
- **他のネットワーク**: 他のサービスでお持ちのアカウントを連携すると、そのサービスはそのアカウントを通じて投稿した内容を受け取り、このサーバーは、そのサービス上であなたの代わりに操作するための認証情報を保存します。他のネットワーク向けのアカウントをここでホストする場合、そのネットワークのサーバーやサービスは、アカウントの公開アドレスとともに、そのネットワークに公開した内容を受け取ります。

## あなたの権利

居住地によっては、個人データへのアクセス、訂正、エクスポート、利用制限、または削除を求める権利が認められる場合があります。データのエクスポートとアカウントの閉鎖は、設定からご自身で行うことができます。アカウントを閉鎖すると、アカウントは猶予期間中ロックされ、その間はサインインして閉鎖を取り消すことができます。その後、アカウントとそのデータはこのサーバーから削除されます（バックアップ保管および特定の記録を保持する法的義務に従います）。その他の権利を行使する場合、またはサインインできない場合は、**{{operator.email}}** までメールでお知らせください。

## データの保持

アカウントデータは、アカウントが有効である限り、また閉鎖後も誤削除からの復旧と法令上・監査上の義務を満たすために合理的な期間保持します。バックアップは通常 90 日間まで保持されます。
