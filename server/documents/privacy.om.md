# Iccitii Mochi

Beeksisni iccitii kun akkaataa **{{operator.name}}** (hojjetaan sarvera Mochi kanaa) yeroo ati akkaawuntii uumtu yookaan tajaajila kana fayyadamtu daataa dhuunfaa kee itti walitti qabu, itti fayyadamuu fi itti qooduu ibsa. {{operator.name}} too'attuu daataati.

## Maal walitti qabna

Yeroo ati galmooftee sarvera kana fayyadamtu nuti walitti qabna:

- **Daataa akkaawuntii**: maqaa fayyadamaa, mala mirkaneessaa kan filattu (teessoo email, passkeys, app mirkaneessituu, koodii deebisuu, yookaan akkaawuntii kan dhaabbata seenaa qaama sadaffaa), fi odeeffannoo profaayilaa kan ati dabaltu kamiyyuu (maqaa agarsiisuu, avatar, seenaa gabaabaa).
- **Qabiyyee ati uumtu**: maxxansa, ergaa, yaada, faayilii, fi daataa kan biraa kan ati app sarvera kana irra jiru fayyadamuun maxxansuu filattu hunda.
- **Qabiyyee namoota biroo**: maxxansa, ergaa, fi odeeffannoo profaayilii namoota sarverota Mochi biroo fi netiwoorkiiwwan biroo irra jiranii, kan sababa ati yookaan fayyadamtoonni biroo isaan hordofan, isaanitti galmaa'an, yookaan isaan waliin wal quunnamaniif sarvera kana ga'an.
- **Gabaasawwan**: gabaasni ati waa'ee nama tokkoo gootu, yookaan namni tokko waa'ee kee godhu, Mochi irratti yookaan netiwoorkii biraa irraa, akka bulchitoonni sarvera kanaa tarkaanfii irratti fudhachuu danda'aniif ni kuufama.
- **Daataa teeknikaa**: teessoo IP, odeeffannoo browser/meeshaa, fi yeroo gaaffii ati gootuu hunda. Kun tajaajila nageenyaan ittisuu fi hojjechiisuu fi miidhaa adda baasuu keessatti fayyadamna.
- **Cookies**: cookie tursiisaa yeroo seentu qabamti. Eenyummeessituu tursiisaa qoricha hin qabne qofa kuusa; cookies beeksisaaf yookaan hordoffii saayitii gidduu hin fayyadamnu.

Daataa dhuunfaa kee hin gurgurru, beeksistootatti immoo hin qoodnu.

## Mochi akkamitti daataa kee qabata (kun barbaachisaa dha)

Mochi **netiwoorkii peer-to-peer (P2P)**, malee veebsaayitii sarvera tokkoo miti. Kun akkaataa daataan kee itti yaa'u, kan iccitii keetiif barbaachisaa ta'e jijjiira:

- Qabiyyeen ati hordoftootatti, abbootii ramaddii, yookaan iddoo waliin qoodamutti maxxansitu **sarverota Mochi biroo**, kan hordoftoota ykn abbootii ramaddii sana qabachiisanitti dabarsama. {{operator.name}} sarverota inni hin hojjechiifne irraa daawwannaa qabiyyee kee balleessuu hin danda'u. Yoo maxxansa balleessite, sarverri kun gosa balleessuu peer kanneen duraan maxxansa erge sanatti erga; balleessuun kun yaaliidhaan kan raawwatamu yoo ta'u, qooda walta'iinsa peer kanaa irratti hundaa'a.
- **Eenyummaan kee (maqaa fayyadamaa, profaayilii, public keys)** yoo profaayilii uummataa filatte, daayirektoorii Mochi keessatti maxxansama, kanaaf fayyadamtoonni Mochi biroo si argachuu fi si quunnamuu danda'u.
- Qabiyyeen kallattii fi dhuunfaa (drafts, qabannoo dhuunfaa, ergaa dhuunfaa fudhattoota addaa gidduutti) sarvera kana fi sarverota fudhattoota qofa irra hafa; kun kutaa netiwoorkii P2P uummataa miti.
- Bakka sarverri kun **netiwoorkiiwwan biroo waliin akka walqabattu** siif hayyamu - akkaawuntii tajaajila biraa irratti qabdu walqabsiisuun, yookaan akkaawuntii namoonni netiwoorkiiwwan biroo hordofuu yookaan ergaa itti erguu danda'an asitti qabachiisuun - wanti ati akkaawuntii sanaan maxxansitu yookaan ergitu sarverota netiwoorkiiwwan sanaa irra deema. Isaan sarverota Mochi miti, {{operator.name}} immoo isaan hin hojjechiisu. Akkaawuntiin akkasii netiwoorkii isaa irratti uummataaf ifa, netiwoorkiiwwan tokko tokko irratti immoo akkaawuntiiwwan ati hordoftu, maxxansaaleen ati jaallattu fi, Bluesky irratti, namoonni ati uggurtes uummataaf ifa. Booda waan tokko gulaaluun yookaan balleessuun gaaffii sarveronni sun tuffachuu danda'an erga.
- Namoonni ati isaan waliin chaattii gootu, Mochi irrattis netiwoorkiiwwan biroo irrattis, yeroo ati toora irra jirtu arguu danda'u. Kana qindaa'ina app chaattii keessatti **Yeroo ani toora irra jiru agarsiisi** fayyadamuun dhaamsuu dandeessa.
- Gabaasni ati waa'ee nama sarvera biraa irra jiruu gootu moderetaroota sarvera sanaatiifis ergamuu danda'a, akka gabaasa sarvera kanaatti malee akka gabaasa keetiitti miti: eenyu akka gabaase hin ibsu.

Gabaabumatti: wanti ati Mochi irratti yookaan netiwoorkiiwwan biroo irratti namoota biroo waliin qooduu filattu kamiyyuu, akkaataa karoorsiteen, to'annaa {{operator.name}} alaatti deema. Qabiyyee ati maxxansitu akka email yookaan quunnamtii federated kamiyyuu biraa godhii ilaali.

## Qaamonni sadaffaa

Daataa dhuunfaa hir'ina ta'e qofa, yeroo ati amaloota walqabatan fayyadamtu qaamota sadaffaa kanneen waliin qoodna:

- **Tajaajila email**: email kan alaa baasamuu (koodii seenuu, mirkaneessa teessoo, beeksisa) tajaajilaa SMTP kan {{operator.name}} qopheesseen ergama.
- **Tajaajiloota seenaa qaama sadaffaa**: yoo Google, GitHub, Microsoft, Facebook, yookaan tajaajilaa OAuth biroon seente, tajaajilaan sun akka ati sarvera kana seente beeka, fi teessoo email kee fi daataa profaayilii bu'uura nuuf qooda.
- **Tajaajiloota kaffaltii**: yoo bittaa app gabaa irraan raawwatte, kaffaltiin Stripe (yookaan tajaajilaan kaffaltii kan {{operator.name}} qopheesse) irraan adeemsifama. Odeeffannoo kaardii guutuu hin kuusinu.
- **Tajaajiloota beeksisa push**: beeksisni app Mochi Android irra jiruuf ergaman Firebase Cloud Messaging kan Google tiin geessifamu, kunis mata duree fi barreeffama isaanii ni geessa. Yoo app biraatiin, kan akka app Mastodon, Matrix yookaan XMPP, sarvera kana seente, beeksisni isaa tajaajila push app sun fayyadamuun geessifama, ergaa beeksisni sun waa'ee isaa ta'es of keessatti qabachuu danda'a.
- **Abbaa taayitaa sartifikeetii**: bakka sarverri kun akkaawuntiiwwan Bluesky domain mataa isaa jalatti qabachiisutti, teessoo akkaawuntii tokkoon tokkoon isaatiif sartifikeetiin nageenyaa ni kennama. Abbootiin taayitaa sartifikeetii sartifikeetii kennan hunda galmee uummataa keessatti maxxansu, kanaaf teessoowwan sun achitti tarreeffamu.
- **Netiwoorkiiwwan biroo**: yoo akkaawuntii tajaajila biraa irratti qabdu walqabsiifte, tajaajilli sun waan ati isaan maxxansitu ni fudhata, sarverri kun immoo credential kan achitti bakka kee bu'ee akka hojjetu isa dandeessisu ni kuusa. Yoo akkaawuntii netiwoorkii biraaf asitti qabachiifte, sarveronni fi tajaajilonni netiwoorkii sanaa waan ati itti maxxansitu, teessoo uummataa akkaawuntichaa waliin, ni fudhatu.
