## ہم کیا جمع کرتے ہیں

جب آپ سائن اپ کرتے ہیں اور اِس سرور کا استعمال کرتے ہیں تو ہم جمع کرتے ہیں:

- **اکاؤنٹ ڈیٹا**: ایک صارف نام، آپ کے منتخب کردہ authentication طریقے (ای میل ایڈریس، passkeys، authenticator ایپ، recovery کوڈز، یا کسی فریقِ ثالث لاگ ان فراہم کنندہ کا اکاؤنٹ)، اور آپ کی شامل کردہ کوئی بھی پروفائل معلومات (display نام، avatar، biography)۔
- **آپ کا تخلیق کردہ مواد**: پوسٹس، پیغامات، تبصرے، فائلیں، اور کوئی بھی دیگر ڈیٹا جسے آپ اِس سرور پر انسٹال شدہ ایپس کے ذریعے شائع کرنا منتخب کرتے ہیں۔
- **دوسرے لوگوں کا مواد**: دیگر Mochi سرورز اور دیگر نیٹ ورکس پر موجود لوگوں کی پوسٹس، پیغامات اور پروفائل کی تفصیلات، جو اِس سرور تک اِس لیے پہنچتی ہیں کہ آپ یا دیگر صارفین اُنہیں follow کرتے ہیں، اُنہیں subscribe کرتے ہیں یا اُن سے خط و کتابت کرتے ہیں۔
- **رپورٹس**: کسی کے بارے میں آپ کی کی گئی رپورٹ، یا کسی کی آپ کے بارے میں کی گئی رپورٹ، Mochi پر یا کسی دوسرے نیٹ ورک سے، محفوظ رکھی جاتی ہے تاکہ اِس سرور کے منتظمین اُس پر کارروائی کر سکیں۔
- **تکنیکی ڈیٹا**: IP ایڈریس، براؤزر/ڈیوائس کی معلومات، اور آپ کی درخواستوں کے timestamps۔ یہ سروس کو محفوظ اور فعال رکھنے، اور بدسلوکی کا پتہ لگانے کے لیے استعمال ہوتا ہے۔
- **Cookies**: جب آپ سائن ان کرتے ہیں تو ایک session cookie سیٹ کی جاتی ہے۔ یہ صرف ایک opaque session شناخت کنندہ ذخیرہ کرتی ہے؛ ہم cookies کا استعمال اشتہارات یا cross-site ٹریکنگ کے لیے نہیں کرتے۔

ہم آپ کا ذاتی ڈیٹا فروخت نہیں کرتے، اور اِسے اشتہار دینے والوں کے ساتھ شیئر نہیں کرتے۔

## Mochi آپ کا ڈیٹا کیسے سنبھالتا ہے (یہ اہم ہے)

Mochi ایک **peer-to-peer (P2P) نیٹ ورک** ہے، نہ کہ سنگل سرور پلیٹ فارم۔ یہ آپ کے ڈیٹا کے بہاؤ کو اِس طرح بدلتا ہے کہ یہ آپ کی پرائیویسی کے لیے اہمیت رکھتا ہے:

- وہ مواد جو آپ followers، subscribers یا shared spaces میں شائع کرتے ہیں، وہ **دیگر Mochi سرورز پر replicate کیا جاتا ہے** جو اُن followers یا subscribers کو host کرتے ہیں۔ {{operator.name}} اپنے سرور کے علاوہ کسی سرور سے آپ کے مواد کی کاپیاں حذف نہیں کر سکتا۔ اگر آپ کوئی پوسٹ حذف کرتے ہیں تو یہ سرور اُن peers کو حذف کرنے کا نوٹس بھیجے گا جنہیں اِس نے پہلے پوسٹ بھیجی تھی، لیکن یہ حذف کرنا best-effort ہے اور اُن peers کے تعاون پر منحصر ہے۔
- اگر آپ public پروفائل منتخب کرتے ہیں تو آپ کی **شناخت (صارف نام، پروفائل، public keys)** Mochi ڈائریکٹری میں شائع کی جاتی ہے، تاکہ دیگر Mochi صارفین آپ کو تلاش اور آپ سے رابطہ کر سکیں۔
- براہ راست، نجی مواد (ڈرافٹس، نجی نوٹس، مخصوص وصول کنندگان کے درمیان نجی پیغامات) صرف اِس سرور اور وصول کنندگان کے سرورز پر رہتا ہے؛ یہ public P2P نیٹ ورک کا حصہ نہیں ہے۔
- جہاں یہ سرور آپ کو **دیگر نیٹ ورکس سے جڑنے** دیتا ہے — کسی دوسری سروس پر موجود اپنا اکاؤنٹ link کر کے، یا یہاں ایک ایسا اکاؤنٹ host کر کے جسے دیگر نیٹ ورکس کے لوگ follow کر سکیں یا اُسے پیغام بھیج سکیں — وہاں آپ اُس اکاؤنٹ کے ذریعے جو کچھ شائع کرتے یا بھیجتے ہیں وہ اُن نیٹ ورکس کے سرورز تک جاتا ہے۔ وہ Mochi سرورز نہیں ہیں اور {{operator.name}} اُنہیں نہیں چلاتا۔ ایسا اکاؤنٹ اپنے نیٹ ورک پر public ہوتا ہے، اور کچھ نیٹ ورکس پر وہ اکاؤنٹس جنہیں آپ follow کرتے ہیں، وہ پوسٹس جنہیں آپ like کرتے ہیں اور، Bluesky پر، وہ لوگ جنہیں آپ block کرتے ہیں، بھی public ہوتے ہیں۔ بعد میں کسی چیز میں ترمیم کرنا یا اُسے حذف کرنا ایک درخواست بھیجتا ہے جسے وہ سرورز نظرانداز کر سکتے ہیں۔
- جن لوگوں سے آپ چیٹ کرتے ہیں، Mochi پر اور دیگر نیٹ ورکس پر، وہ دیکھ سکتے ہیں کہ آپ کب آن لائن ہیں۔ آپ اِسے چیٹ ایپ کی سیٹنگز میں **دکھائیں جب میں آن لائن ہوں** کے ذریعے بند کر سکتے ہیں۔
- کسی دوسرے سرور پر موجود کسی شخص کے بارے میں آپ کی کی گئی رپورٹ اُس سرور کے moderators کو بھی بھیجی جا سکتی ہے، آپ کی رپورٹ کے طور پر نہیں بلکہ اِس سرور کی رپورٹ کے طور پر: اِس میں یہ نہیں بتایا جاتا کہ اِسے کس نے کیا۔

مختصر یہ کہ: جو کچھ بھی آپ Mochi پر یا دیگر نیٹ ورکس پر دوسرے لوگوں کے ساتھ شیئر کرنے کا انتخاب کرتے ہیں، وہ ڈیزائن کے اعتبار سے {{operator.name}} کے قابو سے باہر سفر کرے گا۔ شائع کیے گئے مواد کو ای میل یا کسی بھی دیگر federated مواصلات کی طرح سمجھیں۔

## فریقِ ثالث

جب آپ متعلقہ خصوصیات کا استعمال کرتے ہیں تو ہم درج ذیل فریقِ ثالث کے ساتھ کم سے کم درکار ذاتی ڈیٹا شیئر کرتے ہیں:

- **ای میل سروس**: outbound ای میلز (سائن ان کوڈز، ایڈریس کی تصدیق، notifications) {{operator.name}} کے configure کردہ SMTP فراہم کنندہ کے ذریعے بھیجی جاتی ہیں۔
- **فریقِ ثالث لاگ ان فراہم کنندگان**: اگر آپ Google، GitHub، Microsoft، Facebook یا کسی اور OAuth فراہم کنندہ سے سائن ان کرتے ہیں تو وہ فراہم کنندہ جانتا ہے کہ آپ نے اِس سرور پر سائن ان کیا، اور آپ کا ای میل ایڈریس اور بنیادی پروفائل ڈیٹا ہمارے ساتھ شیئر کرتا ہے۔
- **ادائیگی فراہم کنندگان**: اگر آپ کسی marketplace ایپ کے ذریعے خریداری کرتے ہیں تو ادائیگی Stripe (یا جس بھی ادائیگی فراہم کنندہ کو {{operator.name}} نے configure کیا ہو) کے ذریعے process کی جاتی ہے۔ ہم مکمل کارڈ کی تفصیلات ذخیرہ نہیں کرتے۔
- **Push notification سروسز**: Android پر Mochi ایپ کے notifications، Google کی Firebase Cloud Messaging کے ذریعے پہنچائے جاتے ہیں، جو اُن کا عنوان اور متن لے کر جاتی ہے۔ اگر آپ کسی دوسری ایپ، جیسے Mastodon، Matrix یا XMPP ایپ، سے اِس سرور پر سائن ان کرتے ہیں تو اُس کے notifications اُس push سروس کے ذریعے پہنچائے جاتے ہیں جو وہ ایپ استعمال کرتی ہے، اور اُن میں وہ پیغام شامل ہو سکتا ہے جس کے بارے میں notification ہے۔
- **سرٹیفکیٹ اتھارٹی**: جہاں یہ سرور اپنے domain کے تحت Bluesky اکاؤنٹس host کرتا ہے، وہاں ہر اکاؤنٹ کے ایڈریس کے لیے ایک security سرٹیفکیٹ جاری کیا جاتا ہے۔ سرٹیفکیٹ اتھارٹیز اپنا جاری کردہ ہر سرٹیفکیٹ public logs میں شائع کرتی ہیں، اِس لیے وہ ایڈریسز وہاں درج ہوتے ہیں۔
- **دیگر نیٹ ورکس**: اگر آپ کسی دوسری سروس پر موجود اپنا اکاؤنٹ link کرتے ہیں تو وہ سروس وہ سب کچھ وصول کرتی ہے جو آپ اُس کے ذریعے پوسٹ کرتے ہیں، اور یہ سرور وہ credential ذخیرہ کرتا ہے جو اِسے وہاں آپ کی جانب سے کام کرنے دیتا ہے۔ اگر آپ یہاں کسی دوسرے نیٹ ورک کے لیے اکاؤنٹ host کرتے ہیں تو اُس نیٹ ورک کے سرورز اور سروسز وہ سب کچھ وصول کرتی ہیں جو آپ اُس پر شائع کرتے ہیں، اکاؤنٹ کے public ایڈریس سمیت۔
